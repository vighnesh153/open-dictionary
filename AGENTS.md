# Project instructions

## About the project

- **Name**: _Open Dictionary_
- **Author**: _Vighnesh_
- **Description**: _A free simple-to-use English dictionary for everyone_

Maintain a tree of words under the `<WORKSPACE_ROOT>/data` directory.
Each word is split on the letters and each letter is a folder. For example, each word's definition is stored in a `w/o/r/d/_.json` directory where `w`,
`o`, `r`, `d` are the letters of the word.

- `apple` => `<WORKSPACE_ROOT>/data/a/p/p/l/e/_.json`
- `banana` => `<WORKSPACE_ROOT>/data/b/a/n/a/n/a/_.json`
